# Próximos casos e evolução

[Voltar ao portfólio](../README.md)

Esta é uma sequência de possibilidades, não uma lista de entregas já implementadas. A versão atual prioriza três demonstrações executáveis com escopo verificável.

| Prioridade | Possível evolução | O que acrescenta | Critério para entrar |
|---|---|---|---|
| 1 | Vídeo curto dos três casos | Comunicação consultiva e domínio do trabalho | Explicar regra, trade-off e limite sem depender de texto pronto |
| 2 | Camada de BI sobre os dados sintéticos | Ponte com a experiência em Power BI | Modelo legível, indicadores definidos e arquivo público sem conexões reais |
| 3 | App operacional com fila e tratativa | Fluxo completo do diagnóstico à ação humana | Estado persistente, responsável, histórico e testes de transição |
| 4 | RAG com provedor opcional | Geração baseada em fontes | Avaliação independente, revisão de citações, custo e proteção contra vazamento |
| 5 | Banco PostgreSQL com RLS | Isolamento executado na camada de dados | Testes reais com papéis e identidades, não só exemplos de SQL |

Para incluir um novo projeto, ele deve demonstrar uma capacidade diferente. Outro dashboard semelhante amplia volume sem necessariamente ampliar evidência. Cada caso precisa de uma pergunta de negócio, recorte executável, decisões, testes e limites.
